# BiteBack

## Running instructions
Please follow these instructions to run our prototype. Please note that your webcam will be activated for the computer vision aspect of our prototype.
1. Create a python virtual environment using a tool of your choice.
2. Install all the python packages in `requirements.txt`.
3. If you wish to disable all the testing features (most notably the spawning of the window to show your webcam video feed), please feel free to change the value of `testing` in line 6 of `app.py` to `0`.
4. Run `python3 app.py`
5. You can visit our prototype at http://localhost:5000/demo.
